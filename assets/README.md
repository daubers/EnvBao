# Logo assets

The EnvBao mascot: a steamed bun (包, as in OpenBao) with a `>_` terminal prompt for a face.

| File | Use |
|------|-----|
| `logo.svg` | Primary, for light backgrounds |
| `logo-dark.svg` | For dark backgrounds |
| `logo-mono.svg` | Single colour, follows `currentColor` (stamps, print, one-colour contexts) |
| `logo-512.png` | Raster, transparent background |
| `favicon.ico`, `favicon-{16,32,48}.png` | Favicons |

The PNGs are rendered from `logo.svg` with headless Chrome (ImageMagick's built-in SVG renderer drops strokes).
